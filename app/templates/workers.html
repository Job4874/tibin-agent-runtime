Workers

Specialized execution units for full-stack coding tasks. The ManagerAgent routes actions to the right worker; the Defender blocks unsafe actions before they execute.

handyman Available Workers

  • ShellWorker — safe shell commands (foreground & background)
  • FileWorker — file reads, writes, and edits with secret redaction
  • GitWorker — git workflows under workspace/repos
  • CoderWorker — write, analyse, lint, explain, and search code
  • ResearchWorker — find files, grep source, summarise directories
  • BrowserWorker — Playwright-driven browser testing
  • VerifierWorker — HTTP and result verification
  • MemoryWorker — context storage across runs
  • ReportWorker — proof: observations and markdown reports

info Worker Lifecycle

Workers are initialized when the ManagerAgent runs a plan. Each action result passes through the VerifierWorker before being marked successful.

lightbulb If BrowserWorker is reported missing, install Playwright with python3 -m playwright install chromium.
